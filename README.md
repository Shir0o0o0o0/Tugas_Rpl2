
# 🍵 Teh Kataji — Identitas Produk & Perlindungan HAKI

## A. Identitas Produk Perangkat Lunak

| Informasi | Keterangan |
|---|---|
| **Nama Aplikasi** | Teh Kataji (TehKataji berbasis web) |
| **Kategori Produk** | Penjualan Online |
| **Platform** | Web Application |
| **Teknologi** | HTML, CSS, JavaScript, Django, Python, MySQL, Supabase |

### Deskripsi Singkat Fungsi

Teh Kataji adalah aplikasi penjualan online yang dirancang untuk membantu pedagang UMKM dalam melakukan pencatatan transaksi penjualan secara real-time, pencetakan struk, serta manajemen stok barang berbasis cloud menggunakan Supabase.
